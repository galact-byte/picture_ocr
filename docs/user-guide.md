# 使用指南

[返回首页](../README.md)

本工具默认使用通用模板。分类、检查项与报告设置可按工作流程调整；下文的测评命令和等保旧模板说明仅适用于相应场景。

## 项目与采集对象

- 新建时可选择“单系统”或“系统组”，默认跟随当前所在列表。一个独立采集任务可用单系统；需要集中管理多个任务时用系统组。
- 系统组可以先只有一个系统，也可用逗号或顿号一次填写多个名称。编辑独立系统时追加多个名称会转为系统组，首个系统保留原有证据。
- 打开系统后，在左侧添加分类与资产。界面中的“资产”可对应设备、场所或其他采集对象；窄窗口下点击“分类导航”展开侧栏，选中资产后回到内容区。
- 在“模板管理”中维护分类的检查项，也可在资产内直接添加。进入“调整顺序”模式后拖动手柄可排序。
- 为检查项上传、粘贴截图或通过手机采集图片。在“项目信息”中设置报告标题、导出文件名前缀和单位字段；点击“报告”导出 Word，导出前会提示缺失的必填截图。
- 首次使用默认只有“通用分类”和可选的“截图”检查项，单位字段默认选填，可按需要调整。

## 模板预设

预设保存分类、检查项和报告配置，方便不同项目重复使用。所有操作均可在界面完成，无需手写配置文件。

### 导入与切换

1. 在项目列表点击“模板预设”。
2. 点击“导入预设”，选择收到的预设 JSON 文件。
3. 导入成功后再新建项目，使用这套模板。

切换预设只影响之后新建的项目，已有项目保留自己的内容和设置。点击“恢复通用模板”可回到初始模板。

### 保存与分享

1. 打开配置好分类和检查项的项目，点击“另存为预设”。
2. 填写预设名称，确认报告标题、文件名前缀、单位字段名称及是否必填。
3. 点击“设为新建默认”供后续项目使用，或点击“导出预设”保存 JSON，供其他电脑或使用者导入。

预设不包含实际资产、截图、单位填写值或项目身份信息，不能代替项目备份。公开下载包不附带行业专用预设，可自行配置或从已有项目另存。

桌面版与 Web 版的数据和预设相互独立；需要使用同一模板时，请分别导入。

### 旧项目与等保模板

升级不改变旧项目的分类、检查项和图片，旧项目单位字段仍按原规则必填。没有保存过的报告标题和文件名前缀采用通用值，可在“项目信息”中修改。

如果没有保存过默认预设或完成过模板选择，且所有现存系统均可确认使用等保分类，进入项目列表后会询问是否沿用最近修改的等保模板。选择沿用只继承分类、检查项和报告配置，不带入资产、图片与单位填写值；选择“继续使用通用模板”后不再提示。已有默认不会被覆盖，之后仍可在“模板预设”中修改。

使用等保分类添加资产时，空名称框按分类显示机房、交换机等灰色示例；请填写实际名称，示例不会自动生成资产。

## 手机拍照同步

Windows 桌面版与 Web ZIP 都支持“手机局域网采集”。手机无需安装应用，拍照或选图后同步到电脑上的对应系统。

1. 电脑与手机连接同一 Wi-Fi，或让电脑连接手机热点。
2. 在电脑项目列表或工作台点击“手机局域网采集”。
3. 选择手机可访问的 Wi-Fi／热点地址，启动会话后扫码，或在手机浏览器打开链接。
4. 在手机上选择系统、分类、资产和检查项，再拍照或选图。多系统项目可在采集页切换系统，单张图片不超过 10 MB。
5. 等待手机显示保存成功。采集结束后，在电脑上点击“停止会话”。

收起弹窗不会停止会话，点击“采集中”可再次打开。采集时保持电脑应用运行；Web 版还需保持浏览器页面和启动窗口打开。

仅在可信 Wi-Fi 或热点下使用，不要转发采集链接给无关人员。Windows 防火墙询问时，仅允许专用网络访问；手机打不开页面时，检查两端网络、所选地址和防火墙设置。

## 备份、迁移与归档

### 备份与恢复

- 在系统操作菜单选择“导出数据包”保存 ZIP；在目标系统选择“导入数据包”恢复。
- “合并导入”将采集内容合入目标系统；“覆盖导入”会替换目标内容，操作前请先备份。
- 历史 `.evidence` 加密包仍可输入密码恢复，忘记密码无法恢复。日常备份使用 ZIP 即可。

### 批量备份

在同一项目组内或独立系统列表中勾选系统，点击“导出选中”。总 ZIP 内包含各系统独立 ZIP；先解压总包，再导入对应系统包。

搜索后全选仅导出当前可见系统；已归档系统需先恢复。任一系统读取、补图或打包失败时整次停止下载，勾选保留以便重试。

### 数据目录改名、移动或恢复

桌面版提示“重新定位原数据目录”时，选择直接包含 `IndexedDB` 的数据目录本身，确认后读取原项目。也可通过“存储设置”→“更改目录”选择已有数据目录，再按提示重启。重新连接不会复制或覆盖数据库，选择父目录不会自动连接子目录。

恢复包解压后可能多套一层同名文件夹。例如 `恢复数据目录/恢复数据目录/IndexedDB`，应选择内层 `恢复数据目录/恢复数据目录`。确认解压完整后再连接；恢复目录不限定原电脑使用。

### 归档释放空间

通过“存储设置”查看占用，按需归档系统。归档将图片保存到所选目录并释放本地图片空间；请妥善保管归档文件，恢复后才能继续打开和编辑该系统。

## 数据保存与图片状态

项目数据保存在本机，不会自动同步到其他电脑、浏览器或版本。图片导入、报告生成和数据包导出均在本地完成；手机采集时，图片通过所选局域网传到电脑。

Web 数据保存在当前浏览器中。清理站点数据会删除项目，更换浏览器或访问地址也可能看不到原数据。请定期导出 ZIP，避免用隐私模式保存长期项目。

图片读取时显示“加载中…”，图片字节不存在时显示“图片缺失”，读取或解码出错时显示“读取失败”。这些状态不会自动恢复缺失图片。

## 测评命令（可选）

此功能供需要设备核查命令的使用者选用，不影响其他场景的图片采集与报告整理。

在资产页点击“测评命令”，按设备类型、平台和用途查找、复制命令。未搜索时可复制完整分组；搜索时只提供匹配命令的复制。执行环境、版本限制与参数说明单独显示，内置目录包含华为/H3C 网络设备、华为 USG、Linux、Windows 和常用数据库。

- **分类默认**：选好平台，展开“默认平台”，点击“设为分类默认”。当前项目该分类已有和新增资产会按“身份鉴别”“访问控制”“安全审计”等明确检查项用途显示命令。未设置平台时不猜厂商、系统或版本；未知及组合歧义名称不自动关联。
- **资产例外**：为混合平台资产点击“仅用于本资产”，不影响同类其他资产；可点击“恢复分类默认”。仅浏览或切换平台不会保存默认。
- **检查项关联**：“命令”入口默认折叠，展开后查看和复制；无命令时进入选择界面。通过“管理关联”调整，手动选择优先于自动默认；清空后刷新不会重新出现，点击“恢复自动默认”才重新继承。
- **维护命令库**：进入“管理命令库”，选定平台与分组后新增、编辑或删除。删除前确认，保存失败保留输入；“退出管理”返回复制视图。库内修改会同步显示在关联项中。
- **手动复制**：自动复制不可用时，界面会选中完整文本，按 Ctrl+C（Mac 使用 ⌘C）复制。

命令库、默认平台与关联在本机保存，桌面与 Web 各自独立，项目 ZIP、加密包和预设均不包含它们。执行前确认目标平台、权限、版本和占位参数；工具不会远程执行命令。

已知限制：局域网 HTTP 下的双窗口并发关联测试仍有失败，原因待排查。请暂时仅在一个窗口编辑命令库、默认平台与关联，避免同时修改。
