# 统一弹窗与表单界面风格

## 背景
工作台和项目列表的弹窗来自不同开发阶段，圆角、遮罩、标题字号、按钮样式和顺序不一致；工具栏部分按钮缺图标，颜色含义也不统一。

## 要求
- 以工作台工具栏的直角、slate 灰色和蓝色主操作为准，统一普通弹窗的外框、遮罩、标题区、正文、底部操作区、输入框和按钮。
- 保留功能颜色：手机采集浅蓝与采集中绿色、项目信息浅黄色、覆盖导入橙色、合并导入绿色、缺项警告琥珀色和红色、模板必填红色。
- 底部按钮统一为次要操作在左、主操作在右；危险操作使用红色。
- 保留原有的语义颜色：工具栏「手机局域网采集」浅蓝、「采集中」绿色、「项目信息」浅黄；导入的覆盖（橙）/合并（绿）、导入成功（绿）、缺项提醒的琥珀色图标与「继续导出」按钮、模板必填标记（红）。
- 模板管理的行内编辑、删除按钮常显，并可通过键盘和触屏操作。
- 图片查看器、相机等全屏界面不在范围内。
- 不改变各弹窗的业务逻辑和数据写入行为。

## 验收
- `npm run build` 通过。
- 预设、项目列表、归档、局域网上传与选择相关的 Web/桌面端回归脚本通过。
- 隔离数据截图核对新建项目、模板管理、另存为预设、项目信息、存储设置、导入数据包弹窗风格一致。
