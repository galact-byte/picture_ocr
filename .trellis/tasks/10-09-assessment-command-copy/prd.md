# 测评命令快捷复制

## 目标

在资产采集页面就近查看、复制测评命令，减少现场在工具与笔记之间切换。

## 背景与已确认事实

- 用户指定资料目录为 `D:/BaiduSyncdisk/Obsidian/note/工作/等保测评/设备服务器数据库测评`，包括分平台测评笔记、现场粘贴清单及 V5.0 结果记录模板对应的命令。
- 资产只有名称、分类和检查项，没有厂商、操作系统或数据库类型字段；分类支持用户自定义，默认项目可没有分类。依据：`src/types/index.ts:67`、`src/data/defaults.ts:20`、`src/components/ContentArea.tsx:404`。
- 现有界面采用 slate 中性色、蓝色操作按钮与接近直角的边框；共用弹窗样式正在另一任务中整理。依据：`src/components/dialogStyles.ts:1`。
- 用户已审阅设计并批准实施，随后追加命令增删改查与检查项旁同步显示命令。

## 需求

- R1：资产页提供“测评命令”入口，覆盖网络设备、安全设备、服务器、数据库；自定义分类与旧项目同样可用。
- R2：按设备类型与平台查看命令；根据明确的分类名称辅助定位，也允许手动选择。首版包含华为网络设备、H3C 网络设备、华为 USG、Linux（RHEL/CentOS 与 Debian/Ubuntu）、Windows、MySQL/MariaDB、Oracle、达梦、人大金仓、HighGo。
- R3：按核查用途分组，例如版本、身份鉴别、登录失败、访问控制、远程管理、日志审计；支持按标题或命令关键词查找。
- R4：每个命令段可单独复制，当前检查分组可整组复制。复制仅包含当前平台、当前执行环境的命令，保持换行、引号、管道与 SQL 分号；说明、结论模板与不适用版本的命令不混入剪贴板。
- R5：标明必要的执行环境、权限、版本及占位参数。图形界面查看路径独立显示；参数需要现场替换时有明确说明；版本专属命令不混为一组。
- R6：成功与失败均有可见反馈；自动复制不可用时可以选中预览文本手动复制。切换平台、清空搜索、关闭重开与切换资产均保持一致的显示和复制对象。
- R7：桌面版与网页版共享内容，离线可查看；网页局域网 HTTP 场景也须提供可用的复制回退。
- R8：依据用户资料整理并记录来源，核对明显笔误和粘贴问题。仅提供核查命令与必要的查看步骤，发布内容使用通用示例与占位参数，排除客户信息、真实凭证、整改配置命令及模板结论。
- R9：操作不改变项目分类、检查项、图片及其他证据内容；命令界面键盘可操作，长命令和小窗口可以完整查看。

- R10：支持新增、编辑、删除和搜索命令；内置命令可以修改或隐藏，新建命令归入选定平台与单一执行环境分组。命令库在本机持久保存、供所有资产共用，重开应用后保留修改。删除前确认，保存失败保留表单；存储内容异常时不得用默认库覆盖已有修改。

- R11：检查项标题旁提供轻量、默认折叠的命令入口，已关联时就地查看及单段复制；无命令时直接进入选择界面。命令库编辑后同步显示最新内容；手动关联按项目、资产、检查项隔离并在本机保存。没有适用命令（如门禁）时不自动挂载无关命令。
- R12：现场复制优先，命令库的编辑、删除归入独立管理模式；搜索直接展示匹配命令及所属用途，搜索结果不提供含未显示命令的整组复制。命令区采用紧凑排列，保留完整代码和必要的权限、版本、参数提示，成功反馈靠近操作位置。
- R13：同一项目的分类可一次选定默认命令平台，该分类的已有和新增资产依据明确的检查项用途自动显示对应命令，不要求逐资产逐检查项绑定。混合平台允许单台覆盖并恢复分类默认；未选定平台时不猜测服务器操作系统、厂商或版本。默认匹配仅使用受控检查项名称及别名，不对任意文本模糊关联。
- R14：已有手动关联优先于自动默认；用户可单独调整、清空某检查项关联及恢复自动默认。分类/平台默认改变不覆盖已有手动选择，取消最后一条默认关联后刷新不得重新出现。旧项目无需重建或导入；所有辅助配置保留在本机，打开、匹配和配置不得改写项目文档与图片。

## 验收标准

- AC1（R1、R2）：分别在四类资产、自定义分类和无分类资产打开入口；类别选择可变更，旧项目无需补录平台字段。
- AC2（R2、R3、R5、R8）：每个平台都有来自指定资料的命令；分组、关键词搜索、执行环境与版本说明可核对；有资料来源清单。
- AC3（R4、R6）：单段与分组复制的真实剪贴板文本逐字匹配所选命令，至少覆盖多行 Linux、网络设备命令、Windows CMD 和带分号 SQL；说明与其他平台命令不出现在结果中。
- AC4（R5、R6）：切换平台/分组、搜索无结果、关闭重开、切换资产后复制对象正确；复制拒绝、API 缺失时明确提示并提供手动选择；不同环境命令无法误合并。
- AC5（R7）：在隔离 Electron 和浏览器实际点击复制并读回；覆盖 localhost 与局域网 HTTP 回退；断网后可打开命令界面。
- AC6（R9）：操作前后项目数据不变；Esc 关闭、Tab 顺序与焦点恢复正确；375px、768px、1280px 下主要控件可操作，长命令不撑破弹窗。

- AC7（R10）：实际新增、编辑、删除与搜索命令，刷新/关闭重开后核对持久化；内置命令修改和隐藏同样保留。空标题/命令、保存失败、损坏存储和删除取消有明确反馈，不丢弃编辑文本、不覆盖已有存储。

- AC8（R11）：关联内置和自定义命令后在检查项旁查看并复制；库内编辑、删除、刷新和跨窗口变更同步反映。取消关联仅影响当前检查项；检查项重命名/排序后关联保留；切换资产或项目不串用关联，读取/保存异常不覆盖旧关联、不误报成功。三档宽度可操作，关联和复制不改变截图粘贴目标。

- AC9（R11、R12）：截图核对默认折叠、无命令直接选择、命令紧凑展示；查看模式每段不常显编辑删除。搜索命令正文只显示匹配段，搜索组标题显示该组各段，无结果与清空正确；复制反馈就近显示，保留失败回退。
- AC10（R13、R14）：隔离创建十台同分类服务器，一次设置平台后各台相同用途检查项都有默认命令，新增和旧资产一致；Windows 单台覆盖不串入 Linux 命令，恢复分类默认后回到分类平台；未设置平台、门禁、未知及歧义检查项不猜测。手动关联不被覆盖，清空、刷新、恢复默认和跨窗口同步正确；操作前后项目文档和图片引用逐字不变。

## 范围

本次交付内置命令参考、快捷复制及命令增删改查。远程执行、SSH 连接、命令输出自动采集、自动测评结论、配置整改及 Obsidian 自动同步留给独立需求。

## 审阅决策

用户已批准命令增删改查、检查项命令入口；本轮批准精简界面和使用路径，并追加旧项目与同类多资产默认关联，避免重复配置。保留资产页入口与居中弹窗，编辑采用独立管理模式；原 `preview.svg` 为早期参考，当前验收以紧凑命令区和默认继承场景的运行截图为准。
