# 技术设计

## 领域与职责

新增共享 `ProjectProfile`：`reportTitle`、`exportFilePrefix`、`unitFieldLabel`、`unitFieldRequired`。`ProjectPreset` 为 `version: 1`、`name`、`categories`、`profile`。预设只包含模板，不含资产实例、图片或项目元数据。

项目文档/摘要及项目组保存可选 profile 字段，内存态使用已解析的完整 profile。独立的纯函数模块负责通用值、旧项目兼容值、JSON 校验、深拷贝和导出文件名净化；界面与存储层复用这些函数，不复制协议校验。旧项目 fallback 是固定值，不读取全局默认。

通用初始内容为“通用分类”，一个可选“截图”检查项，无假设备资产；用户先添加自己的资产。保留模板支持的 checklist/freestyle 两种类型。分类通过 reducer 的 ADD_CATEGORY / RENAME_CATEGORY 创建与改名，保留稳定 ID，拒绝空名称；不引入删除分类功能。

## 数据流

预设 JSON → unknown 运行时校验 → IndexedDB 默认预设记录 → 新建对话框加载并展示 → 用户提交时使用该次加载的快照 → ProjectDocument / ProjectGroup → reducer/Context → 文档及摘要同事务保存。

项目配置 → Word 封面与文档属性、ZIP/DOCX/加密包文件名、单位标签与必填校验。

当前项目 categories + profile → 可编辑的预设保存表单 → JSON 下载；选择设为新建默认时另行写入默认预设。两项操作分别报告结果，写库失败不能显示成功。

## 存储与兼容

- 默认预设存于当前数据库新增 `settings` store 的固定键；先确认不存在等价 store。数据库版本只在此需要时递增。onupgradeneeded 仅创建结构，保留旧升级路径约束。
- 无默认记录时使用通用内置值；读取失败须显示错误并允许重试，不能静默用通用模板创建错误项目。
- 新建表单使用已加载配置做校验，提交采用同一快照，防止异步更换预设造成校验和最终文档不一致。
- 新组保存 profile；组内新系统使用组的 profile，分类取当次新建默认预设。已有系统保留自己的 profile；组级单位编辑按组及成员必填要求处理，不能绕过任一成员的必填规则。
- 旧组/旧文档无 profile：固定兼容单位名称+必填，报告标题与前缀采用固定通用值（已批准 A 方案）；严禁随全局默认漂移。
- profile 在 normalize、摘要生成、LOAD_PROJECT、IMPORT_DATA、buildDocument、包导入/导出、归档/恢复链路透传；合并导入保持目标 profile，覆盖导入使用包 profile，旧包使用旧项目 fallback。
- 明确保存的空 categories 保持空；仅缺字段时用通用兜底，不以全局预设覆盖已有文档。
- 不做启动时全库迁移。旧文档按读取归一化，在原有正常保存路径存入固定配置；列表仍只读摘要。

## 外部输入

预设文件限 1 MiB；拒绝未知版本、非对象、错误字符串/布尔类型、不支持的分类类型、无效顺序、重复分类 ID、重复模板 ID。限制分类/模板数量及字符串长度并给出具体错误；只提取允许字段。任何校验失败不写默认记录。

标题等文本 trim 后不得为空；单位值可空由 required 决定。文件名前缀/元数据在下载命名边界净化路径分隔符、控制字符、Windows 非法字符、尾随点与空格；结果为空用通用名。包格式保持向后可读，新增 profile 可选。

## 界面

沿用现有 slate/blue 功能型 UI，不改版。项目列表提供“预设”入口：导入为新建默认、恢复通用默认；工作台现有模板/设置入口承担分类新增/改名、报告设置和“另存为预设”。具体复用位置依组件证据选择，不重复创建设置体系。

单位自定义标签用于表单、工作台及报告提示；混合配置的列表表头使用中性表述，必要时行内显示字段名。无单位的可选项目报告不出现“请填写”占位提示。

应用可见页面标题改成通用名称；保留 package productName/appId、数据库名、origin、dataLocation 目录常量等兼容标识。本次不把它们视作模板硬编码清除，避免改变数据定位。

## 回滚与发布

实施前将当前默认模板完整保存到 gitignored 本地预设，校验数量和文字一致；不要把内容复制进受追踪测试夹具。验证使用通用虚构模板。

不对用户真实库进行迁移或测试。若新增 DB 版本已在真实环境打开，不可直接降版本；需保持版本并回滚业务逻辑，或恢复用户自行保存的完整备份。本次只完成本地实现/验证，发布版本另行确认。
