# 测评命令快捷复制设计

## 用户路径与界面

1. 在资产页“添加检查项 / 调整顺序”一行新增次要按钮“测评命令”。排序模式下隐藏该入口，避免叠加操作。
2. 打开居中弹窗，标题“测评命令”，副标题为当前资产名称。顶部两个原生选择框为“设备类型”“平台”，搜索框提示“搜索检查项或命令”。
3. 左侧是该平台的核查分组，右侧显示当前组的命令段。顶部显示组名、执行环境与次要“复制本组”；各段紧凑标题行主要操作为“复制”。浅灰代码区使用等宽字体，允许选中文本与横向滚动。编辑、删除仅在明确的管理模式下显示；保留可访问的退出管理入口。
4. 以实际运行的三档宽度截图审阅，沿用项目接近直角的样式，减少重复描边大按钮与说明块，不修改共用弹窗样式及其他弹窗。
5. 命令库分组保留稳定 ID；默认关联通过受控检查项名称/别名映射到用途分组，兼容旧项目没有模板引用的检查项。只规范化空白、常见编号前缀和标点；歧义、未知名称不匹配，不从客户资产名、IP 猜平台。

## 边界与结构

- `src/data/assessmentCommands.ts`：静态类型化目录、平台及命令段，纯数据，无外部请求与运行代码。
- `src/utils/assessmentCommands.ts`：类别名称辅助匹配、关键词过滤、分组复制文本生成等纯函数，仅在确有独立职责时抽出。
- `src/components/AssessmentCommandDialog.tsx`：选择、分组导航、显示和复制反馈。
- `src/components/ContentArea.tsx`：一个打开状态与入口，传入资产 ID、名称和分类名。
- 使用浏览器现有 Clipboard API；受限时用当前用户点击内的隐藏 textarea + `execCommand('copy')` 回退，保留并恢复原焦点/选择。两种方式都失败时选中该命令预览并显示“请按 Ctrl+C 手动复制”，不可假报成功。
- 不引入依赖，不改项目文档类型、项目证据 IndexedDB schema、导入导出和设备服务，不在 Electron 主进程加无必要的桥。

## 数据契约

```ts
type CommandFamily = 'network' | 'security' | 'server' | 'database';
interface CommandSnippet {
  id: string;
  title: string;
  command: string;
  note?: string;
}
interface CommandGroup {
  id: string;
  title: string;
  environment: string;
  note?: string;
  snippets: CommandSnippet[];
  viewingSteps?: string[];
}
interface CommandProfile {
  id: string;
  family: CommandFamily;
  label: string;
  groups: CommandGroup[];
}
```

一组只有一个执行环境。同一平台的 SQL 与宿主机 Shell 分成不同组；Oracle SQL*Plus、数据库 SQL、Windows CMD 标注准确。H3C 与华为分为独立平台，避免同时复制两种取消分页指令。HighGo V4/V6 与 V9 需要不同命令时分成平台变体，而非在整组内混放。静态 ID 以本工具职责命名，来源目录名称不成为公共接口。

复制文本以 `snippets.map(snippet => snippet.command).join('\n\n')` 为基础；预览渲染同一字符串，任何说明存在独立字段。无搜索时提供当前完整分组复制；有搜索时按标题、命令、说明匹配命令段，组标题匹配则展示该组全部命令，显示所属用途，不提供整组复制。无结果显示空态。

## 命令增删改查与本机保存

用户批准实施并追加命令增删改查。当前分组提供“新增命令”，命令段提供“编辑 / 删除”。编辑视图在当前弹窗内显示标题、命令多行文本和说明；平台和分组在进入编辑前选定，每组执行环境明确，保存后返回当前组并清除搜索以显示新命令。取消或关闭有未保存编辑时确认，删除在弹窗内独立确认状态处理，避免叠加焦点约束。

`src/utils/assessmentCommandStore.ts` 负责本机 localStorage 命令覆盖层：新增记录、内置命令替换、删除标记。小规模纯文本库采用同步 localStorage，不增加项目数据库迁移，不保存项目证据。运行时检查版本、平台/分组引用、ID、文本类型和长度；读失败/损坏时内置库仍可查看复制，写入禁用并明确提示，不覆盖原始内容。写失败保留编辑表单；所有生产写入异步取得 `withCommandWriteLock` 后，在一个同步回调中完成现读、校验、冲突检查和 setItem，订阅 storage 事件同步其他窗口的变更。自定义库按应用本机存储保留，项目数据包不携带该库。

### 跨窗口写入互斥

命令库与关联共用独立辅助 IndexedDB `evidence-command-write-lock` 的 `mutex` object store。每次写入新建同一 store 的 readwrite 事务，在 get 请求成功回调内同步完成 localStorage 整库读改写；跨连接事务由 IndexedDB 排队，不依赖安全上下文限定的 Web Locks，兼容局域网 HTTP。该库只提供互斥，不保存命令、绑定或项目证据，不接触项目数据库，也不引入数据迁移。

写入入口返回 Promise，UI 等待实际 setItem 成功后才刷新、关闭表单和报告成功；等待时阻止重复提交、关闭及变更编辑对象。读写失败、取得锁失败/中止或等待超过 10 秒均拒绝写入，保留原数据和草稿，不降级成无锁写入。锁回调不得异步等待或嵌套取得锁；连接在事务终态关闭，迟到的打开/请求不执行已失败的写入。

localStorage 与 IDB 无法组成原子事务：成功点是锁内同步 setItem 返回，空辅助事务稍后结束只释放互斥。不得因 setItem 后的辅助事务中止把已写入误报为失败，也不得回滚覆盖其他窗口的新数据。保证适用于全部采用此写入入口的同源窗口，旧版本未取得锁的窗口及开发者工具直接写入不在互斥范围内。

编辑字段错误逐项显示，使用 aria-invalid 和 aria-describedby 关联标题、内容、说明的错误文本，聚焦首个错误字段；存储失败是表单级错误，不能把有效字段标记成非法。

## 检查项命令关联

检查项标题旁“命令”入口默认折叠；有命令时展开紧凑区域，无命令时直接打开同一弹窗选择。行内共用平台/执行环境提示，必要警告保留而相同组说明去重；不再显示无意义的“在此查看复制”占位说明。复制反馈靠近对应按钮并使用 aria-live，失败保留完整手动文本。“管理关联”以当前检查项为目标；每段提供关联/取消关联，保留手动跨平台选择，但不提供跨环境合并复制。

关联在独立 localStorage 键下保存稳定命令 ID，按 `[projectId, assetId, itemId]` 定位，不复制命令正文。共用库解析结果经 `useAssessmentCommandLibrary` 下发给检查项，库内写入后立即刷新，同源其他窗口用 storage 事件刷新。删除命令后保留引用并显示失效提示，用户可以单独取消失效关联；不静默显示旧正文。绑定读取/写入做格式和容量校验，失败保留原存储。该本机辅助配置与命令库一样不包含在项目导出包中。检查项重命名与排序不改 ID，因此关联保留；删除后关联不被其他检查项复用。

`ItemCommandPanel` 封装行内展示和复制状态，在组件卸载或目录变更后忽略旧复制结果；命令区阻止点击冒泡，避免选择截图粘贴目标。长命令只在自身区域滚动；排序视图不显示命令操作。

## 分类默认平台与自动关联

- 新增独立辅助配置键保存分类平台 `[projectId, categoryId] -> profileId` 和资产覆盖 `[projectId, assetId] -> profileId`，复用现有锁、容量/运行时校验、错误保护与 storage 同步。明确设置作用域，分类操作提示影响本分类全部未覆盖资产，默认不覆盖单台设置；支持单台恢复分类默认。浏览弹窗选择平台不等于保存分类配置，使用显式按钮保存。
- 有效平台为资产覆盖优先、分类默认其次；未设置时仅允许浏览，不生成默认关联。用户仅需为同分类选一次平台，无需逐台选命令。命令弹窗打开时跟随已配置平台。
- 自动关联只在渲染时派生：受控检查项用途匹配 -> 有效平台的最新分组 -> 命令 ID。支持身份鉴别、访问控制、安全审计/日志审计、登录失败、远程管理、版本等明确名称/别名。普通“截图”、门禁或组合歧义名称保持未匹配。不修改项目 schema、模板和导入导出，不做批量项目迁移。
- 手动绑定 v1 原键保留：键存在即完整覆盖默认，包括空数组。旧非空绑定行为不变；从默认开始调整时以当前有效 ID 列表为基线，锁内读取最新覆盖，不丢其余默认项。取消最后一条写入空数组而不是删除键；“恢复默认”显式移除该键。命令删除后的手动失效引用仍提示，默认命令从最新目录派生。
- 配置损坏时不回退猜测平台，不覆盖存储，禁用相关保存；项目证据不受影响。所有测试使用隔离 Chrome userData、测试项目和 Electron profile，不打开或改写真实浏览器库。当前连接浏览器未打开用户 Web 项目，未获得真实检查项样本，不宣称真实项目匹配已验证。

## 状态与生命周期

- 首次打开：已设置平台则优先使用；否则以明确分类名称辅助浏览设备类型，该浏览默认不产生自动关联，始终允许手动切换。不得根据资产 IP 或任意名字猜测产品版本。
- 同一资产关闭重开：保留本次页面会话的平台选择，搜索/复制提示清空。切换资产：重新按分类定位并清空分组与搜索。无需持久化用户证据。
- 更换类型/平台：重置分组到第一个可见组，清除陈旧成功/失败提示。搜索使所选组不可见时重新选可见首组。
- 空组只有查看说明时，隐藏无意义的复制按钮。
- 复制中暂时禁用对应按钮，结果用 `role=status`/`aria-live=polite` 宣布；旧复制结果不得覆盖新平台提示，卸载时清理计时器。
- 弹窗采用 `role=dialog`、`aria-modal`、标题关联、初始焦点、Tab 焦点约束、Esc 关闭与恢复触发按钮焦点。

## 风格与响应式

沿用当前工作台及 `dialogStyles.ts`；若另一任务未完成，按其可用状态复用，勿重做整套弹窗基础组件。主区域白底、slate 描边、浅灰代码，复制为蓝色主要操作，其余中性按钮，接近直角。字体沿用本地字体栈，离线不取 CDN。点击区域至少 44px，焦点可见，成功状态有文字。

1280px 为约 1000px 宽弹窗，768px 缩减间距，375px 切成上下布局，用原生分组选择替代左栏。最大高度 90vh，头尾固定、内容区滚动，代码横向滚动，不压缩字体掩盖长命令。仅颜色反馈，尊重减少动效设置。

## 兼容与回退

新目录随双端前端构建交付，离线可用；不读用户 Obsidian 绝对路径。分类名只是初始选择的便利，不是入口权限。无需数据迁移。回退只需移除入口和新模块，不涉及用户存储。当前其他弹窗修改属于另一任务，禁止覆盖或归入本任务成果。
