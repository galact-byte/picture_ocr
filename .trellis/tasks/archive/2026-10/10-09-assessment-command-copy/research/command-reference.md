## 静态设计稿中的样例

这些只读查询由 Linux 笔记及 V5.0 整理中的身份鉴别部分得到；按发行版拆出文件路径。设计稿采用 RHEL/CentOS 视图，Ubuntu 的 `common-password` 在其对应平台显示。

### 身份鉴别：用户列表（Linux Shell）

```bash
getent passwd
```

来源：V5.0 整理第 77 行。显示账号清单，不根据单条命令自动判断所有账号口令合规。

### 身份鉴别：密码复杂度（RHEL/CentOS）

```bash
cat /etc/pam.d/system-auth
cat /etc/pam.d/password-auth
```

来源：Linux 笔记第 17–18 行。PAM 路径依发行版而异；部分配置需管理员权限。

### 身份鉴别：密码有效期与默认策略

```bash
cat /etc/login.defs
```

来源：Linux 笔记第 27 行。这个文件显示默认策略，既有账号的实际密码有效期需要另外查看，不把默认策略当作所有用户的实际结果。

## 复制与内容审核准则

- 每段 command 字段只存可粘贴命令。说明字段存执行位置、权限、版本、依赖与参数替换要求。
- 保留真实 shell 管道和 SQL 分号，去掉错误的 `#`/`##` SQL 注释与行末裸中文。
- 查询与核查步骤按需要纳入，整改语句不纳入。Windows 策略导出会写临时文件，应标明该步骤的实际作用。
- 查询敏感身份信息时说明管理员权限与核查用途；样例中不放真实输出、客户名称、生产 IP、凭证及现场截图。
- 对参数值的解释和推导核对范围：全局 SSL 开关与当前连接 SSL 状态不同，默认 profile 与实际用户 profile 不同。
- 没有真实设备/数据库环境时如实标记验证方式为内容核对与复制验证，不能声称命令都已在目标产品执行成功。
