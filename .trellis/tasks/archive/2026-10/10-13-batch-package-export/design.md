# 批量数据包导出设计

## 边界与复用

- `ProjectList.tsx` 管理选中项、导出状态、按钮入口和中文提示；继续使用 `selectedVisibleSystems`，不改变删除或搜索范围。
- `ProjectListHeader.tsx` 接受批量导出回调与忙碌状态，在独立系统工具栏提供操作。项目组入口放在现有已选操作区，避免引入重复选择弹窗。
- `src/utils/exportImport.ts` 承担批量 ZIP 编排与下载，复用 `loadProject`、`hydrateAssets`、`createDataPackageBlob`、`sanitizeFileNamePart` 和已安装 JSZip，不复制 manifest 或加密协议。
- 不改 `ExportPackage`、IndexedDB 结构或 Electron IPC。

## 产物契约

批量入口生成一次下载的总 ZIP：

```text
批量数据包_20261013.zip
├── 证据采集_项目名_系统甲_20261013.zip
├── 证据采集_项目名_系统乙_20261013.zip
└── ...
```

每个子 ZIP 的根目录仍为 `manifest.json` 和 `images/`，profile 和现有模板信息按单系统逻辑透传。系统名称使用文档中的当前名称，空名称使用既有回退规则。前缀、项目名和系统名净化后分别限制为 60 个 UTF-16 单元，截断末尾不保留单独的高代理字符，以保留系统标识并控制解压文件名长度；本次 ZIP 内按大小写不敏感规则去重，重复追加序号，防止 Windows 解压时覆盖；路径分隔符不能逃出包内根目录。

总包是下载容器，不作为单系统包导入。按钮附近给出简短的“解压后可逐个导入”说明，README 补充恢复步骤。即使批量入口只选中一个系统，也保持总包形式；单系统菜单仍生成原有 ZIP。

## 数据流

1. 点击时取当前可见选中系统的 ID 与名称快照，去重并拒绝空集合。
2. 快照包含归档摘要时提示先恢复，整次停止。
3. 顺序以 `loadProject(id, { migrateLegacy: false })` 读取每个系统文档；列表已处理旧单项目初始化，这里跳过迁移读写事务。不存在、读失败或最新文档带 archive 标记即报出系统名称并停止。
4. 调用 `hydrateAssets(projectId, assets)` 补齐字节，逐个检查所有图片引用均有非空 data。该函数在缺图时原样保留引用，必须显式拒绝，不能让 `buildDataPackageZip` 跳过图片后生成看似成功的包。
5. 调用既有 `createDataPackageBlob` 生成子 ZIP，净化并去重文件名后加入总 ZIP；只把子 ZIP 留在总包中，不缓存全部已补齐文档。回调进度供 UI 展示。
6. 全部子包完成后生成总 ZIP 并仅调用一次现有下载辅助函数。任何阶段出错都不下载部分结果。
7. finally 释放忙碌状态；错误走 `useToast`，选择保留以便重试。完成提示说明文件已生成并发起下载。

## 生命周期与竞争

- UI 导出状态保留在列表本地；用同步 guard 避免快速双击在 React 更新前发起两个任务；组件卸载时 abort，最终下载前检查取消信号。
- 导出期间固定快照并禁用会更改当前选择/源系统的相关入口，避免本窗口同时删除、导入、压缩或编辑；结束后恢复。切页/打开系统等会卸载或改变操作上下文的动作在忙碌时禁用。
- 每个系统在实际处理时重读文档，不依赖列表摘要判断归档或存在性。其他窗口和手机采集可能持续更新数据，本功能不承诺跨系统同一时刻的事务快照。
- 不新增全局缓存、持久任务或进度写库；不修改后台图片迁移的既有流程。

## 交互与视觉

- 沿用项目 slate/blue/red 配色、`LIST_ACTION_CLASS`、现有网格和断点。导出在删除前，删除保留危险色语义。
- 显示已选数量、生成进度与收尾打包状态；状态使用 `role=status` 或 aria-live，按钮具备 native disabled、可见焦点和至少 44px 点击高度。
- 已选操作区允许 flex 换行，小屏移到下一行，不压缩系统名称列；不为了新按钮改全局字号或布局。
- 已按 `frontend-design`、`reference.md` 与 `ui-ux-pro-max` 读取要求评估。UI Skill 的设计系统检索包含营销页面布局与新字体建议，与本项目功能型工具语境不符；依据项目本土规则沿用现有视觉，仅采纳可访问性、忙碌反馈、对比度与响应式检查。

## 取舍、兼容与资源限制

- 一个总 ZIP 避免多次下载权限及十几次保存提示；恢复需要先解压。直接批量导入需要新协议与目标映射，超出本任务。
- 顺序打包控制同时持有的文档和图片数据，不用 Promise.all 读取全部系统。JSZip 仍需在内存保留所有子 ZIP 与最终产物，批量体积越大峰值越高；不宣称流式或恒定内存。
- 失败整次停止，确保下载文件包含全部选择，避免用户把部分包当完整备份。
- 本功能只读取源数据并发起下载，可通过移除入口和批量编排局部回滚，无数据迁移。
